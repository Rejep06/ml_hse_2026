# Wine Quality — интерактивный отбор вин

Веб-приложение к домашнему заданию (часть 4). Предсказывает вероятность того, что вину поставили оценку **7 и выше**, и показывает, как изменяются рекомендации при изменении порога. **В приложении модель не обучается.**

## Состав папки

- `app.py` — четыре вкладки приложения Streamlit;
- `model.joblib` — обученный пайплайн `StandardScaler + LogisticRegression`;
- `config.json` — порог, выбранный **на валидации** (`0.268`);
- `test.csv` — тестовая выборка для построения матрицы ошибок и кривых;
- `requirements.txt` — зависимости приложения;
- `sample_input.csv` — 5 примеров для проверки вкладки пакетного предсказания (без `target`).

## Запуск

Проверено обучение модели на **Python 3.14**. Для локального запуска используйте Python 3.14 (либо совместимый интерпретатор с указанными зависимостями).

```bash
# Находясь в каталоге, где лежит wine_app/
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r wine_app/requirements.txt
python -m streamlit run wine_app/app.py
```

В боковой панели можно менять порог (значение по умолчанию из `config.json`). Изменение порога **не переобучает** модель.

## Что делает каждая вкладка

1. **Одно вино:** 11 числовых признаков с диапазонами и медианами из `test.csv` и переключатель `is_red`. Показывает вероятность класса 1 и решение при текущем пороге.
2. **Модельные метрики:** текущие precision, recall, F1, матрица ошибок, ROC и PR-кривые с точкой текущего порога.
3. **Проверить CSV:** загрузка таблицы без `target`, проверка названий столбцов и числовых значений, просмотр и скачивание результатов. Если какой-то признак отсутствует, выводится предупреждение вместо падения.
4. **Коэффициенты модели:** горизонтальные столбики весов после стандартизации, отсортированные по значению. Это ассоциации модели, а не доказательство причинно-следственной связи.

## Почему два вида кэша

- `st.cache_resource` используется для **объекта модели**: один раз загружает `joblib`, хранит общий ресурс между перезапусками скрипта.
- `st.cache_data` используется для **DataFrame и рассчитанных вероятностей на тесте**: повторные вызовы с теми же входными данными не читают CSV и не запускают `predict_proba`; Streamlit возвращает копии результатов.
- Без декоратора вызов `joblib.load()` повторялся бы при каждом изменении ползунка, хотя файлы модели не меняются.
- `cached_test_proba(features, _model)` исключает модель из хеширования (имя аргумента с `_`). Для обновления самой модели перезапустите приложение с очисткой кэша.

## Деплой на Streamlit Community Cloud

1. Создайте GitHub-репозиторий и загрузите папку `wine_app/` вместе с `model.joblib`, `config.json`, `test.csv`, `requirements.txt` и `app.py`.
2. В Streamlit Community Cloud создайте приложение, выберите репозиторий и ветку.
3. Укажите основной файл **`wine_app/app.py`** (если репозиторий содержит папку `wine_app`) или `app.py` (если файлы лежат в корне).
4. Укажите Python 3.14, если он доступен, или совместимый интерпретатор, и нажмите Deploy.
